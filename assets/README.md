`search-clear.png` is Chromium's original search-field cancel icon, used to match the Settings close button to the browser's search clear button.

`forms/` contains Pokémon item sprites from
https://github.com/PokeAPI/sprites/tree/master/sprites/items, downloaded by
`scripts/update_form_requirements.mjs` for the alternate-form divider. The
Gigantamax category uses the Dynamax Band; the existing Mega symbol stays in
`mega-evolution.png`. Pokémon names and artwork belong to their respective owners.
